# Utiliser Mistral Vibe avec Byobu et XFCE 

Configuration pour serveur X:

```
    $ sudo dnf install xsel 
    $ vim ~/.byobu/.tmux.conf 

    # Pas indispensable 
    set -g mouse on

    # Permet l'utilisation de shift up/down pour Vibe 
    unbind-key -n S-Up
    unbind-key -n S-Down

    # Permet de sélectionner du texte puis pendant la sélection d'utiliser CTRL MAJ C pour copier dans le presse papier
    set -s copy-command 'xsel --clipboard --input'
    set -s set-clipboard off
```
